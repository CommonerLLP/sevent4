Where this console's data comes from

Every layer, number, and name on the Delhi console traces to one of the source records below. A record without a link means the source's public URL was never captured at acquisition time — that gap is reported, not papered over with a guessed link.

boundary dataset
ECI assembly/parliamentary constituency boundaries via DataMeet (datameet/maps) source

Election Commission of India delimitation geometry redistributed by DataMeet. Backs acs.geojson (70 ACs, 2008 delimitation) and pcs.geojson (7 PCs; PC file URL recorded as https://raw.githubusercontent.com/datameet/maps/master/parliamentary-constituencies/india_pc_2019_simplified.geojson in the same record). Also feeds the derived jurisdiction_crosswalk.json. License recorded as 'DataMeet community data'.

boundary dataset
Delhi municipal wards (pre-2022 interim) via DataMeet (datameet/Municipal_Spatial_Data) source

Backs wards.geojson (~290 pre-2022 charges incl. NDMC + Cantonment; predates the 2022 unified-MCD 250-ward delimitation — shipped as labelled interim per CREDITS.md caveat). Ward geometry also underlies ward_heat.geojson, ward_heat_summary.json, ward_aqi.geojson, jurisdiction_crosswalk.json, and the ward attribution inside shelters.geojson. License CC BY-SA 2.5 IN.

boundary dataset
Villages Maps of Delhi (OpenCity, Government of Delhi KML, 2022) source

Backs villages.geojson (district-tagged village polygons, 2022) and districts.geojson (11 districts dissolved from the village polygons per scripts/recipes/delhi/build_opencity_layers.py). Per-resource download URLs and checksums are in data/cities/delhi/source/opencity/_raw/_manifest.json.

facility register
Delhi Water Bodies Census Data (OpenCity, 2023 KML) source

Backs water.geojson (893 water-body points, 2023), converted from KML by build_opencity_layers.py.

air quality dataset
Delhi Hourly Air Quality Reports (CPCB/DPCC/IMD CAAQMS data via OpenCity) source

Publisher recorded as central-pollution-control-board; per-station CSVs 2017-2023 (DPCC/IMD monitors). Backs air_quality.geojson and ward_aqi.geojson (built by scripts/recipes/delhi/build_air_quality.py from _raw/delhi-hourly-air-quality-reports/).

air quality stations
CAAQMS monitoring-station coordinates (station_master.csv, source tag 'cpcb_caaqms') no public URL recorded

Station lat/lon and operating agency (DPCC/IMD etc.) for the air_quality.geojson / ward_aqi.geojson station points. The on-disk record tags each row source=cpcb_caaqms but records no URL for the CPCB portal itself — honest blank; the build script header confirms coordinates come from this curated master, not Google Maps.

gtfs feed
Open Transit Data Delhi — static GTFS bundle (GNCTD) source

Public no-key static GTFS download (OTD_STATIC_URL in the delhi-acquire adapter). Backs bus_routes.geojson (route LineStrings from shapes.txt / longest-trip reconstruction per scripts/recipes/delhi/acquire_gtfs.py).

osm extract
OpenStreetMap via Overpass API (amenity/transit/road queries) source

Overpass queries defined in sevent4/domain/delhi_acquire.py back stops.geojson (highway=bus_stop), metro.geojson (subway stations), metro_lines.geojson, rrts.geojson (Namo Bharat), rail.geojson, roads.geojson (motorway/trunk/primary 'Major roads'), health.geojson, schools.geojson, police.geojson, fire.geojson, toilets.geojson. OSM is reference-tier in this atlas, ODbL 1.0.

osm extract
New Delhi OSM shapefile extract (BBBike, OpenStreetMap contributors) source

2026-01-09 snapshot, ODbL 1.0. Only the waterways layer was ingested — backs drains.geojson (975 drainage/canal/river segments clipped to the NCT ward union); roads/rail/points/buildings explicitly NOT ingested (recorded as redundant/rejected in the same sources.json).

facility register
Delhi Public Library zone pages (branch locations register) source

DPL-published branch/sub-branch locations parsed from dpl.gov.in zone pages (source_url column per row), geocoded with confidence flags. Backs dpl_libraries.geojson.

library annual reports
Delhi Public Library annual reports (dpl.gov.in) source

Per-year report PDFs with sha256 in the fetch manifest (e.g. https://dpl.gov.in/images/annualreport910.pdf). Backs the DPL metrics time series (dpl_annual_metrics.csv, dpl_ten_year_time_series.csv) used by the library analysis behind dpl_libraries.geojson attributes — not a separate map layer. The archive manifest records that a later re-fetch of dpl.gov.in failed (connection timeouts) and that 2012-13 was obtained via a Google Drive mirror URL recorded therein (data/cities/delhi/source/libraries/dpl_annual_report_archive_manifest.csv).

shelter register
DUSIB (Delhi Urban Shelter Improvement Board) district-wise night shelters / live occupancy report source

Backs shelters.geojson. Provenance is embedded per-feature ('source' field: DUSIB District wise Night Shelters List, live occupancy report, fetched 2026-07-01 11:03 IST), with per-feature geocode_confidence and ward-vintage caveat notes.

satellite derivation
Microsoft Planetary Computer STAC — USGS Landsat Collection 2 Level-2 (Landsat 8/9) land surface temperature source

Heat layers are a derivation, not a downloaded dataset: the adapter queries collection 'landsat-c2-l2' filtered to platforms landsat-8/landsat-9 and computes a QA-masked LST median. Backs ward_heat.geojson, ward_heat_summary.json (window 2024-04-01/2026-07-01 recorded in the file), heat30m.png and heat30m_bounds.json. Quarterly refresh via .github/workflows/heat-refresh.yml.

Handling & reuse

This inventory is compiled from the repo's own acquisition records: each entry is backed by a named internal record whose existence is verified every time this page is built. It is also published as machine-readable JSON (schema sevent4.public_sources.v1) so other projects can reuse the sourcing without re-deriving it.
