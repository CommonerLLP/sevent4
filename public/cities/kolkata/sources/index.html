Where this console's data comes from

boundary dataset
DataMeet maps (Census 2011 districts, Assembly and Parliamentary constituencies) source

DataMeet community maps repo, CC-BY-SA 2.5 IN. Backs districts.geojson (dists11.geojson filtered DISTRICT=Kolkata), acs.geojson (ac.geojson filtered DIST_NAME=KOLKATA, ACs 158-168), pcs.geojson (pc_14.geojson filtered to Kolkata Uttar/Dakshin). The ac.geojson and pc_14.geojson URLs are recorded verbatim in the same file. Also the AC/PC inputs to the derived jurisdiction_crosswalk.json (spatial join of ward/AC/PC layers, per the crosswalk's own embedded source field).

shelter register

Sole source for shelters.geojson — all 6 Kolkata features carry this URL in their per-feature source field, with geocode-confidence and site-visit notes embedded per feature (6 NULM-registered shelters, 437 beds).

scheme norm pdf
DAY-NULM Scheme of Shelters for Urban Homeless (SUH) operational guidelines source

PRIMARY-VERIFIED 2026-07-01 (Section 3.1, printed p. 2); local copy at data/sources/nulm-suh-guidelines-day-nulm-2019.pdf. Provides the shelter-capacity norm behind the Kolkata shortfall benchmark (~90% short, 437 beds vs ~4,497 norm-implied) that contextualizes shelters.geojson.

Handling & reuse

This inventory is compiled from the repo's own acquisition records: each entry is backed by a named internal record whose existence is verified every time this page is built. It is also published as machine-readable JSON (schema sevent4.public_sources.v1) so other projects can reuse the sourcing without re-deriving it.
