# Kochi / Ernakulam Facility Source Index

Authoritative open-data and government sources for facility lists serving the
Kochi Municipal Corporation area. (Kerala = devolution control group; state open
data and departmental directories are strong, though a single corporation-run
facility roster on the corporation portal was not located in this pass.)

## Health
- **Ernakulam District (NIC) hospital directory** — https://ernakulam.nic.in/en/public-utility-category/hospitals/
  (Government hospitals incl. General Hospital Ernakulam (est. 1845, 783 beds),
  Taluk Hospital Tripunithura, Women & Children Hospital Mattancherry.)
  Note: page timed out on automated fetch; URL verified live via search index.
- **State Health Agency (SHA) Kerala — empanelled hospital list (PDF)** —
  https://sha.kerala.gov.in/wp-content/uploads/2020/12/Kerala-Hospital-List-Public.pdf
- **SHA Ernakulam public hospitals** — https://sha.kerala.gov.in/?page_id=507&lang=en
- **National Health Mission Kerala / Arogyakeralam** — https://arogyakeralam.gov.in/
- **data.gov.in** — National Hospital Directory + All India Health Centres Directory
  (CHC/PHC/FHC geocoded). Kerala: ~226 CHCs, ~885 FHCs, ~849 PHCs statewide.

## Libraries
- **Ernakulam Public Library** (est. 1870, oldest/largest in Kerala) —
  https://www.ernakulampubliclibrary.com/
- Kerala State Library Council (grama/public library network) — state directory
  is the authoritative aggregate; per-corporation extract not pulled this pass.
