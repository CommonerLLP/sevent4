# KMC Official Facility Lists

All files below were downloaded from the Kolkata Municipal Corporation official site
(`kmcgov.in/KMCPortal/downloads/`) on 2026-06-09. Each returned HTTP 200 with a valid PDF.

## Health
- `KMC_Health_Units.pdf` — Source: https://www.kmcgov.in/KMCPortal/downloads/Health_Unit.pdf
  Ward/UPHC list with addresses + medical-officer names & phone numbers.
- `KMC_UPHC_2019.pdf` — Source: https://www.kmcgov.in/KMCPortal/downloads/UPHC_19_09_2019.pdf
  Urban Primary Health Centre details by ward (dated 19-09-2019).

## Education / Schools
- `schools/School_Borough_<I..XVI>.pdf` (all 16 boroughs) —
  Source pattern: https://www.kmcgov.in/KMCPortal/downloads/School_Borough_<ROMAN>.pdf
  KMC primary school list per borough: school code, full address, school type, classes.
  (KMC runs ~358 primary schools.)
- `KMC_Education_Dept_2013.pdf` — Source: https://www.kmcgov.in/KMCPortal/downloads/EDU_PD_18_09_2013.pdf
  Education department / project-directorate listing (2013).

## Parks & Gardens
- `KMC_Parks.pdf` — Source: https://www.kmcgov.in/KMCPortal/downloads/Parks.pdf
  Parks & Squares Department list / achievements.

## Governance reference
- `borough_chairmen.csv` — 16 borough chairpersons with ward groupings + mobile numbers.
  Source: https://www.kmcgov.in/KMCPortal/outside_jsp/KMC_Borough_Chairman_08_07_2015.jsp

## Not captured / gaps
- A consolidated public-library list was NOT found as a KMC-hosted PDF (KMC's remit is
  schools/health/parks; public libraries in Kolkata fall under the WB State Central
  Library / Dept of Mass Education Extension, not KMC). Flagged for the libraries pass.
- School PDFs date stamping not embedded; treat as latest-published, not real-time.
